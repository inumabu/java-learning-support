# 📋 要件 Skeleton

## 🎯 目的

Java を学ぶ人が、講義・サンプルコード・演習・進捗を一つの Web サイトで扱える基盤を作る。

## 👥 想定ロール

- 学習者: コース閲覧、課題提出、進捗確認
- 講師: コンテンツ作成、提出確認、フィードバック
- 管理者: ユーザー、権限、運用設定の管理

## 🧩 非機能要件

- Java 21 / Spring Boot
- Oracle Database を正本とする
- 日本語 UI とレスポンシブ画面
- CI でテストとパッケージを再現可能にする
- 秘密情報をソースコードに含めない

## 🚫 Skeleton で未実装

認証、ユーザー管理、課題採点、コード実行、決済、通知、Oracle Migration は未実装です。
